Proxmark3GUI Modern
===================

Proxmark3GUI Modern is a Windows-focused modernization of the original
Proxmark3GUI project by wh201906:

https://github.com/wh201906/Proxmark3GUI

The original project history is intentionally preserved so upstream authors and
contributors remain credited by GitHub and by the repository log.

The project is distributed under LGPL-2.1, matching the inherited upstream
license. The `LICENSE` file contains the unmodified LGPL-2.1 license text.

Proxmark3GUI Modern is designed for use with the RRG/Iceman Proxmark3 client,
which is a separate project:

https://github.com/RfidResearchGroup/proxmark3
